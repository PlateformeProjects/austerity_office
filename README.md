# Le Bureau de la Rigueur 🏢✨

"Rendre les gens moins cons, un clic à la fois."

Cette application est une suite d'outils satiriques conçus pour démasquer le manque de professionnalisme au bureau avec élégance et sarcasme.

## Fonctionnalités

- **Traducteur de Langue de Bois** : Découvrez ce que vos collègues pensent vraiment derrière leurs phrases corporate.
- **Générateur d'Excuses de Merde (G.E.M.)** : Ne soyez plus jamais à court d'arguments bidons pour justifier vos retards.
- **Compteur de Coût de l'Incompétence** : Calculez précisément combien d'argent votre entreprise perd en réunions inutiles.

## Installation et Lancement

1. Installez les dépendances :
   ```bash
   npm install
   ```

2. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```

## Design
L'application arbore un style "Moderne & Sarcastique", mélangeant l'esthétique propre des startups de la Silicon Valley avec un ton passif-agressif assumé.
